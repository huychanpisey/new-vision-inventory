# ប្រព័ន្ធគ្រប់គ្រងសារពើភ័ណ្ឌ និងស្តុក - សាលារៀន ញូវវីសិន (New Vision School)

ប្រព័ន្ធនេះត្រូវបានបង្កើតឡើងសម្រាប់គ្រប់គ្រងការទិញចូល ការស្នើសុំ និងបញ្ចេញសម្ភារៈ ព្រមទាំងការគណនាស្តុកនៅសល់ និងតម្លៃសរុបនៃសារពើភ័ណ្ឌរបស់សាលារៀន **New Vision** ដោយមានទាំងឯកសារ **Excel (.xlsx)** ដែលមានរូបមន្តស្វ័យប្រវត្ត និងផ្ទាំង **Interactive HTML Web Dashboard** ទំនើប។

## 🌟 កំណែទម្រង់ និងមុខងារថ្មីៗបន្ថែម (Latest Updates)

1. **ការកែសម្រួលផ្ទៃខាងលើ (Header Background) និងពណ៌ប៊ូតុង**៖
   - ប្ដូរផ្ទៃខាងលើ (Header) ទៅជា **ពណ៌ស្វាយរាជវង្ស (Royal Purple Gradient)** យ៉ាងស្រស់ស្អាត។
   - កែសម្រួលពណ៌ប៊ូតុងមុខងារនានាកុំឱ្យជាន់គ្នា និងមានភាពលេចធ្លោខ្ពស់៖
     - **កត់ត្រាទិញចូល**៖ ពណ៌បៃតងត្បូងមរកត (Emerald Green)
     - **ស្នើសុំចេញស្តុក**៖ ពណ៌ទឹកក្រូចមាស (Amber Gold)
     - **Import ទិន្នន័យ**៖ ពណ៌ខៀវទឹកសមុទ្រ (Teal Cyan)
     - **របាយការណ៍ស្តុក**៖ ពណ៌ផ្កាកុលាបដិត (Vibrant Rose)
     - **ទាញយក Excel**៖ ពណ៌បៃតងចាស់ (Forest Green)
     - **បោះពុម្ព**៖ ពណ៌កញ្ចក់ថ្លាប្រាក់ (Silver Glass)

2. **ការរំលេច Tab ដែលកំពុងបើកមើល (Active Tab Highlight)**៖
   - រំលេចយ៉ាងច្បាស់នូវ Tab ណាមួយដែលកំពុងបើកមើល ដូចចំណុច Tick ដែលបានស្នើសុំ។
   - មានបំពាក់សញ្ញា Tick ផ្លូវការ `[ ✓ សកម្ម ]` និងពន្លឺ Gradient រួមទាំង Ring ភ្លឺច្បាស់ ងាយស្រួលដឹងថាកំពុងនៅទំព័រណា។

3. **ប្រព័ន្ធតម្រៀបទិន្នន័យលើក្បាលតារាង (Clickable Column Sorting)**៖
   - អាចចុចលើក្បាលជួរឈរ (Column Headers) នៃតារាងទាំង ៣ (បញ្ជីស្តុកមេ, ទិញចូល, ចេញស្តុក) ដើម្បី Sort ពីតូចទៅធំ (A → Z) ឬពីធំទៅតូច (Z → A) ដោយមានបង្ហាញសញ្ញាព្រួញ Sort យ៉ាងច្បាស់។
   - គាំទ្រការតម្រៀបតាមអក្សរខ្មែរ (Khmer Unicode), លេខសម្គាល់ ID, ចំនួនស្តុកនៅសល់, តម្លៃសរុប, កាលបរិច្ឆេទ...។
   - មានប្រអប់ Dropdown រហ័សសម្រាប់ជ្រើសរើសការតម្រៀបពេញនិយមភ្លាមៗ។

4. **ប្រព័ន្ធទាញយករបាយការណ៍បច្ចុប្បន្នភាពស្តុក (Periodic Inventory Status Reports)**៖
   - **ទម្រង់ឯកសារ**៖ អាចទាញយកជា **Word (`.doc`)** និង **Excel (`.xlsx`)** ឬ **បោះពុម្ព / PDF**។
   - **កាលកំណត់គាំទ្រ**៖
     - 📅 **ប្រចាំសប្ដាហ៍ (Weekly)**
     - 🗓️ **ប្រចាំខែ (Monthly)**
     - 📊 **ប្រចាំត្រីមាស (Quarterly)** (Q1, Q2, Q3, Q4)
     - 🎓 **ប្រចាំឆមាស (Semester)** (ឆមាសទី១, ឆមាសទី២)
     - 🏆 **ប្រចាំឆ្នាំ (Annual / Yearly)**
     - ⚡ **បច្ចុប្បន្នភាពជាក់ស្តែង (Live Snapshot / All-Time)**
     - ⚙️ **ចន្លោះកាលបរិច្ឆេទកំណត់ដោយខ្លួនឯង (Custom Date Range)**
   - **លក្ខណៈសម្បត្តិនៃរបាយការណ៍**៖
     - ក្បាលលិខិតផ្លូវការ៖ ព្រះរាជាណាចក្រកម្ពុជា ជាតិ សាសនា ព្រះមហាក្សត្រ និង ក្រសួងអប់រំ យុវជន និងកីឡា
     - តារាងសង្ខេបបច្ចុប្បន្នភាពស្តុក (KPI Summary): មុខទំនិញ, ស្តុកដើមគ្រា, ទិញចូលក្នុងគ្រា (+), ចេញស្តុកក្នុងគ្រា (-), ស្តុកចុងគ្រា, និងតម្លៃស្តុកសរុប ($)
     - តារាងទិន្នន័យលម្អិតពេញលេញគ្រប់មុខសម្ភារៈ
     - ប្លុកហត្ថលេខា ៣ ភាគីផ្លូវការ៖ អ្នករៀបចំរបាយការណ៍, ប្រធានផ្នែកស្តុក, និងនាយកសាលា (អនុម័ត)

5. **ប្រព័ន្ធ Import ទិន្នន័យពីឯកសារខាងក្រៅ (Universal File Importer)**៖
   - គាំទ្រឯកសារ Excel (`.xlsx`, `.xls`), Word (`.docx`, `.doc`), CSV (`.csv`), JSON (`.json`), TXT (`.txt`)។
   - ចែកចាយទិន្នន័យចូល Sheet នីមួយៗដោយស្វ័យប្រវត្ត (Auto-Distribution)។

6. **ប្រព័ន្ធគ្រប់គ្រងផ្នែក បុគ្គលិក និងប្រភេទសម្ភារៈ (Full CRUD Management)**៖
   - អាចបន្ថែម កែប្រែ និងលុប ផ្នែក/ដេប៉ាតឺម៉ង់ បុគ្គលិក និងប្រភេទសម្ភារៈបានដោយផ្ទាល់។

7. **ក្រាហ្វិកស្ថិតិសម្ភារៈដែលស្នើសុំច្រើនជាងគេ (Top Most Requested Items)**៖
   - បង្ហាញពីមុខសម្ភារៈដែលបានប្រើប្រាស់ច្រើនជាងគេក្នុងសាលា ជាមួយប័ណ្ណចំណាត់ថ្នាក់ 🥇 លេខ ១, 🥈 លេខ ២, 🥉 លេខ ៣។

8. **បំពាក់ Logo សាលា និង Logo ក្រសួងអប់រំ យុវជន និងកីឡា (MoEYS)**៖
   - Logo សាលារៀន ញូវវីសិន នៅខាងឆ្វេង និង Logo ក្រសួងអប់រំ យុវជន និងកីឡា នៅខាងស្តាំបង្អស់នៃ Dashboard។

9. **ប្រព័ន្ធភ្ជាប់ Google Sheets ផ្ទាល់ (Cloud Real-Time Sync — ជម្រើសទី ២)**៖
   - ផ្ទាំង Web Dashboard ឥឡូវនេះអាចតភ្ជាប់ទិន្នន័យផ្ទាល់ជាមួយ Google Sheets តាមរយៈ **Google Apps Script Web App API**។
   - គ្រាន់តែបិទភ្ជាប់ (Paste) Web App URL នោះ Dashboard នឹងទាញយកទិន្នន័យ (Sync) ចុងក្រោយបង្អស់ពី Google Sheets មកបង្ហាញលើក្រាហ្វិក និងតារាងដោយស្វ័យប្រវត្ត។
   - មានឯកសារកូដគំរូ [Google_Apps_Script_Code.js](file:///d:/projec_inventory/Google_Apps_Script_Code.js) ស្រាប់ សម្រាប់ Copy ដាក់ចូល Google Sheets ក្នុងរយៈពេលត្រឹមតែ ២ នាទី។

10. **ប្រព័ន្ធគ្រប់គ្រងបញ្ជីបុគ្គលិក & សម្ភារៈកាន់កាប់ (Sheet 5: Staff Directory & Custody Management)**៖
    - បន្ថែម Tab ទី ៥ នៅលើរបារម៉ឺនុយ **«Sheet 5: គ្រប់គ្រងបុគ្គលិក & សម្ភារៈកាន់កាប់»**។
    - **Import & Export បញ្ជីបុគ្គលិក**៖ អាចទាញយកបញ្ជីបុគ្គលិក និងសម្ភារៈកាន់កាប់ជា Excel (`.xlsx`) ឬ Import បញ្ចូលពីខាងក្រៅ។
    - **បច្ចុប្បន្នភាពសម្ភារៈដែលគាត់មាន (Active Assets in Custody)**៖ បង្ហាញសម្ភារៈ/ឧបករណ៍ដែលបុគ្គលិកម្នាក់ៗកំពុងកាន់កាប់ជាក់ស្ដែង (ចំនួនបានទទួល ចំនួនបានប្រគល់ត្រឡប់ និងចំនួននៅសល់)។
    - **មុខងារប្រគល់សម្ភារៈចូលស្តុកវិញ (Return to Stock)**៖ នៅពេលបុគ្គលិកយកសម្ភារៈមកជូនវិញ (ដូចជា Laptop, Projector, សៀវភៅ...) ប្រព័ន្ធនឹងកត់ត្រាការប្រគល់ត្រឡប់ ហើយបូកស្តុកត្រឡប់ចូលស្តុកមេវិញដោយស្វ័យប្រវត្ត។
    - **ប្រវត្តិស្នើសុំសម្ភារៈទាំងអស់ (Complete Request History)**៖ បង្ហាញប្រវត្តិគ្រប់ប្រតិបត្តិការដែលបុគ្គលិកម្នាក់ៗធ្លាប់បានស្នើសុំ។
    - **ប័ណ្ណប្រគល់-ទទួល និងកាន់កាប់សម្ភារៈ (Official Custody Voucher)**៖ បង្កើត និងបោះពុម្ពប័ណ្ណផ្លូវការសម្រាប់បុគ្គលិកម្នាក់ៗ មានទាំងប្លុកហត្ថលេខា ៣ ភាគី (បុគ្គលិក, រដ្ឋបាល, នាយិកា)។

## 📁 ឯកសារក្នុងគម្រោង

1. **`index.html`**: ផ្ទាំង Web Dashboard ទំនើប អាចបើកប្រើប្រាស់លើ Browser ណាក៏បាន (Offline 100% ឬភ្ជាប់ Cloud Google Sheets)។
2. **`Google_Apps_Script_Code.js`**: កូដ Google Apps Script សម្រាប់ដំឡើងក្នុង Google Sheets ដើម្បីធ្វើជា Cloud API ភ្ជាប់ជាមួយ Dashboard។
3. **`New_Vision_School_Inventory.xlsx`**: ឯកសារ Excel មេផ្លូវការ មាន ៤ Sheets (Master Inventory, Stock In, Stock Out, Settings)។
4. **`START_DASHBOARD.bat`**: ចុចពីរដង (Double-click) ដើម្បីបើកដំណើរការ Dashboard HTML ភ្លាមៗ។
5. **`assets/`**: ផ្ទុក `school_logo.png`, `moeys_logo.svg`, និងបណ្ណាល័យ Local JS (`xlsx.full.min.js`, `mammoth.browser.min.js`)។
